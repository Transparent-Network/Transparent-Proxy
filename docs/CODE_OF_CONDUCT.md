コントリビューター行動規範（Code of Conduct）
私たちの約束（Our Pledge）

私たちメンバー、コントリビューター、ならびに運営者は、年齢、体格、目に見える／見えない障害、民族性、性の特徴、ジェンダー・アイデンティティおよび表現、経験レベル、学歴、社会経済的地位、国籍、外見、人種、宗教、性的指向や性的アイデンティティに関わらず、すべての人にとってハラスメントのない参加体験を提供することを約束します。

私たちは、開かれていて、歓迎的で、多様性があり、包摂的で、健全なコミュニティに貢献する行動と対話を行うことを誓います。

行動基準（Our Standards）
望ましい行動の例

以下は、コミュニティにとって前向きな環境を作る行動の例です。

他者に対して思いやりと親切さを示すこと

異なる意見、視点、経験を尊重すること

建設的なフィードバックを与え、また誠実に受け取ること

自身の誤りに責任を持ち、影響を受けた人に謝罪し、そこから学ぶこと

個人の利益だけでなく、コミュニティ全体にとって何が最善かを考えること

許容されない行動の例

以下の行為は容認されません。

性的な言葉や画像の使用、またはあらゆる形での性的な注目・誘導行為

荒らし行為、侮辱的・中傷的なコメント、個人または政治的な攻撃

公的・私的を問わないハラスメント

明示的な許可なく、他者の個人情報（住所、メールアドレスなど）を公開すること

職業的・専門的な場において不適切と合理的に判断されるその他の行為

運営者の責任（Enforcement Responsibilities）

コミュニティ運営者は、許容される行動基準を明確にし、これを執行する責任を負います。
不適切、脅迫的、攻撃的、または有害と判断される行為に対しては、公平かつ適切な是正措置を取ります。

運営者は、本行動規範に沿わないコメント、コミット、コード、Wiki編集、Issue、その他の貢献を削除・編集・却下する権利と責任を有し、必要に応じてその判断理由を説明します。

適用範囲（Scope）

この行動規範は、すべてのコミュニティ空間に適用されます。
また、個人が公式にコミュニティを代表して公の場で行動する場合にも適用されます。

コミュニティを代表する行為の例には、以下が含まれます。

公式メールアドレスの使用

公式SNSアカウントでの投稿

オンライン／オフラインイベントで、任命された代表者として行動すること

執行ガイドライン（Enforcement Guidelines）

運営者は、違反の影響度に応じて、以下のガイドラインに基づき対応を判断します。

1. 是正（Correction）

コミュニティへの影響
不適切な言葉遣いや、非専門的または歓迎されない行動。

対応
違反内容と不適切である理由を説明する、運営者からの非公開の書面による注意。
場合によっては、公的な謝罪を求めることがあります。

2. 警告（Warning）

コミュニティへの影響
単発、または一連の行為による違反。

対応
今後同様の行為を行った場合の結果を明示した警告。
一定期間、関係者や運営者への接触（未承諾の連絡を含む）を禁止します。
この制限には、コミュニティ内だけでなくSNSなど外部チャネルも含まれます。
条件に違反した場合、一時的または永久的な追放につながる可能性があります。

3. 一時的な追放（Temporary Ban）

コミュニティへの影響
継続的または重大な違反行為。

対応
指定された期間、コミュニティとのあらゆる公開・非公開のやり取りを禁止します。
この期間中、運営者や関係者への未承諾の接触は禁止されます。
違反した場合、永久追放となる可能性があります。

4. 永久追放（Permanent Ban）

コミュニティへの影響
継続的な規範違反、個人へのハラスメント、特定の集団に対する攻撃や差別的言動。

対応
コミュニティにおけるすべての公開活動から永久に追放されます。
